# Provider logos

Brand marks for the Providers page, mapped to provider ids in
[`model/providers.ts`](../../model/providers.ts). The logos are their owners'
trademarks, used to identify each provider.

- Color logos, with separate light and dark files where the brand has them:
  [svgl](https://svgl.app) (`https://svgl.app/library/<file>`).
- `lobehub-*`: brands svgl lacks, from LobeHub's
  [`@lobehub/icons-static-svg`](https://github.com/lobehub/lobe-icons) (MIT).
  The ones without `-color` are one-color and draw in the text color.

To add one, save the SVG here and add it to the provider's entry.
